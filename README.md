# DevFørge — Elite Developer Workspace

The ultimate developer cockpit combining terminal emulation, code editing, system monitoring, C++ memory allocation simulation, Python data pipeline visualization, and build orchestration.

## Features

- **Interactive Terminal** — Full terminal with command history, syntax highlighting, and split panes
- **Code Editor** — Monaco-based editor with C++/Python syntax support
- **System Monitor** — Real-time CPU, memory, process, and network monitoring
- **C++ Memory Allocator** — Visual heap allocation simulator
- **Python Data Pipeline** — DAG-based pipeline builder and executor
- **Build Orchestrator** — Multi-stage build pipeline with live logs
- **Command Palette** — ⌘K fuzzy search for all commands
- **5 Themes** — Dark, Light, Cyberpunk, Forest, High Contrast
- **Keyboard Shortcuts** — Fully keyboard-driven navigation
- **Responsive** — Works on all screen sizes

## Tech Stack

- Next.js 15 (App Router)
- React 19 + TypeScript (strict)
- Tailwind CSS + Framer Motion
- Zustand (state management)
- Recharts (charts)
- shadcn/ui components
- Monaco Editor
- Three.js / React Three Fiber
